# LLM Wiki Jev 0.7.0

首次发行的 Jev 开源分支，基于 [nashsu/llm_wiki](https://github.com/nashsu/llm_wiki)，保留 GPLv3 许可与原作者声明。

## 本次新增

- 独立的 Jev 设置和连接测试，默认关闭；生成与写作仍由原有 LLM 完成。
- 使用 Jev 复核重复条目候选，页面合并仍需用户确认。
- 抽查来源摘要中的最多五条结论，定位原文并提示矛盾、证据不足或缺失引用。该检查不覆盖整篇 Wiki，也不阻止写入。
- 独立应用名 **LLM Wiki Jev**、配置标识 `io.github.castor6.llmwiki`，更新来源为本仓库。上游应用的全局设置不会自动迁移。

## 下载与使用

- macOS：Apple Silicon（ARM64）的 `.dmg`，本次没有 Intel Mac 包。
- Windows：`.msi` 或安装 `.exe`；`windows-x64-portable.zip` 为便携包。
- Linux：按机器架构选择 x86_64 / amd64 或 ARM64 / aarch64 的 `.deb`、`.AppImage` 等产物。
- `llm-wiki-extension-0.7.0.zip` 为浏览器剪藏扩展。
- `SHA256SUMS` 提供各下载文件的校验值。

此版本的 **macOS 包没有 Developer ID 签名或 Apple 公证，Windows 包也未配置代码签名**。操作系统可能阻止或提示未知发布者；这些包不能视为已完成平台商店或公证验证。

启动后先配置生成模型；如需启用 Jev，在「设置 → Jev」填入自己的 TypeSafe Key 并测试连接。应用和安装包不包含开发者 API Key。Jev 默认使用 `jev-1.13.0`，调用会把相关文本发送到 TypeSafe。

## 验证范围

发布流水线要求单元测试、TypeScript/前端构建、四个平台打包及扩展打包通过，并在公开 Release 前重新下载产物核对 SHA256。基础 Jev 真实接口测试已覆盖中英文合成样例和引用检查 helper；这不等同于真实资料上的模型质量评测或每个平台完整的交互验收。
